# nidox-vpn-detection-defense-skill

`nidox-vpn-detection-defense-skill` — отдельный Codex audit skill для проверки VPN skills на риски обнаружения и сопутствующие сетевые признаки.

Это не репозиторий обычных installation/configuration skills. Его роль ограничена аудитом, аналитикой и оценкой рисков перед применением VPN-навыков в общей инфраструктурной сборке.

## Назначение

Скилл предназначен для проверки VPN skills на следующие категории рисков и артефактов:

- VPN detection risks
- network fingerprints
- DNS leaks
- routing artifacts
- GeoIP / ASN exposure
- false-positive scenarios

## Роль в общей структуре

Этот репозиторий используется как обязательный аудит-модуль для skills внутри `nidox-vpn-skills`.

При этом он остаётся отдельным репозиторием и не должен смешиваться с обычными эксплуатационными навыками, такими как:

- установка и обновление 3x-ui;
- настройка Podkop;
- конфигурация OpenWrt;
- настройка Cloudflare, sing-box, Xray и других инфраструктурных компонентов.

Иными словами, `nidox-vpn-detection-defense-skill` проверяет такие skills, но не подменяет их и не должен содержать их обычные installation/configuration workflows.

## Что содержит репозиторий

Репозиторий содержит:

- `SKILL.md` с правилами работы аудит-скилла;
- `references/official/` с материалами, напрямую подтверждаемыми локально сохранёнными источниками;
- `references/analysis/` с аналитическим слоем и интерпретацией;
- `references/source-map.md` с картой трассируемости;
- `agents/` с инструкцией для специализированного агента;
- `sources/` с исходными файлами и их текстовой копией.

## Принцип использования

Если VPN skill применяется внутри `nidox-vpn-skills`, Codex должен сначала использовать `nidox-vpn-detection-defense-skill` как аудит-модуль, а уже затем переходить к установочным, конфигурационным или эксплуатационным действиям.

Сам по себе этот репозиторий не должен превращаться в общий каталог навыков для 3x-ui, Podkop, OpenWrt и других VPN-компонентов.

## Ограничение источников

Все тексты и выводы в этом репозитории основаны только на локально сохранённых материалах этого проекта. Если нужного тезиса нет в локальных материалах, его нельзя добавлять как подтверждённый факт.

Аналитические файлы в `references/analysis/` используются как интерпретационный слой поверх локальных источников и не заменяют собой первичный материал.
