# nidox-vpn-detection-defense-skill

Локальный проект-репозиторий с Codex Skill на русском языке для анализа схем VPN, Proxy и роутерного проксирования с точки зрения признаков выявления, описанных в открытых материалах NTC по теме «Методичка Минцифры по выявлению VPN».

## Назначение

Репозиторий нужен для локального использования в Codex как специализированный навык, который:

- разбирает схему обхода блокировок по пунктам методики;
- отмечает сильные и слабые признаки возможного детекта;
- учитывает серверные и клиентские факторы;
- предупреждает о ложноположительных срабатываниях;
- опирается только на локально сохраненные материалы этого репозитория.

## Источник материалов

Единственный источник для этого репозитория:

- страница NTC: [https://ntc.rkn.quest/t/методичка-минцифры-по-выявлению-vpn/23842](https://ntc.rkn.quest/t/%D0%BC%D0%B5%D1%82%D0%BE%D0%B4%D0%B8%D1%87%D0%BA%D0%B0-%D0%BC%D0%B8%D0%BD%D1%86%D0%B8%D1%84%D1%80%D1%8B-%D0%BF%D0%BE-%D0%B2%D1%8B%D1%8F%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D1%8E-vpn/23842)
- вложения со страницы:
  - `_VPN_proxy_.pdf`
  - `ocr_methodika_vpn_proxy.md`

Внутри репозитория не используются внешние статьи, сторонние гайды или непроверенные источники.

## Что это такое

Это локальный Codex Skill. Он не предназначен для публикации по умолчанию и не публикуется на GitHub без отдельной команды.

Репозиторий содержит:

- `SKILL.md` с правилами работы скилла;
- `references/official/` с материалами, напрямую подтверждаемыми PDF/OCR;
- `references/analysis/` с аналитическими выводами и интерпретацией;
- `references/source-map.md` с картой трассируемости;
- `agents/` с инструкцией для специализированного агента;
- `sources/` с исходными файлами и их текстовой копией.

## Как подключать и использовать

1. Держать папку проекта локально.
2. Использовать `SKILL.md` как основной файл навыка.
3. При анализе схем сначала обращаться к `references/official/` и `sources/`, а затем при необходимости к `references/analysis/`.
4. Не добавлять внешние утверждения, если они не подтверждены локальными материалами репозитория.

Пример назначения скилла:

- анализ схемы VPN или Proxy по признакам GeoIP, ASN, hosting и репутации IP;
- оценка мобильных признаков на Android и iOS;
- разбор сценария с OpenWrt или podkop, когда проксирование вынесено на роутер;
- выделение слабых мест методики и зон возможных ложных срабатываний.

## Ограничение источников

Все тексты и выводы в этом репозитории основаны только на указанной странице NTC и файлах, сохраненных из нее. Если нужного тезиса нет в локальных материалах, его нельзя добавлять как факт.

Аналитические файлы в `references/analysis/` не являются прямым пересказом источника и должны использоваться как интерпретационный слой поверх официальных материалов.
