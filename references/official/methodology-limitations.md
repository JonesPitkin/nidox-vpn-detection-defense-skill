# Ограничения методики

Этот файл содержит только ограничения, прямо сформулированные в методичке.

## Ограничения GeoIP

См. раздел `5.6. Ограничения GeoIP`:

- мобильные сети;
- CGNAT;
- корпоративные сети;
- пограничные регионы;
- CDN и глобальные сервисы;
- пользовательские Proxy с обычным домашним IP;
- отставание репутационных баз;
- роуминг.

## Ограничения мобильного анализа

См. раздел `6.6. Ограничения Мобильных устройств`:

- резидентные Proxy;
- сценарии с обычным внешним IP провайдера;
- системы приватности и фильтрации, не маркируемые ОС как VPN.

## Ограничения косвенных признаков

См. разделы `7.3.`, `7.6.`, `7.7.`, `7.9.`:

- только косвенные признаки недостаточны для решения;
- маршрутизация не дает однозначного вывода;
- DNS не является самостоятельным доказательством;
- split tunneling, proxy-in-app и кастомные реализации затрудняют выявление.

## Ограничения широты охвата

См. разделы `8.3.` и `8.7.`:

- расширение методики на desktop и UNIX-платформы требует накопления статистики;
- методика не рассматривает ситуацию, когда VPN разворачивается на пользовательском маршрутизаторе;
- методика не рассматривает ситуацию, когда VPN или Proxy разворачивается внутри виртуальной машины или контейнера.
