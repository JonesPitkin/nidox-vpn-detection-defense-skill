# Ложноположительные срабатывания

Этот файл содержит только ложноположительные сценарии и меры снижения ошибок, прямо описанные в методичке.

## Источники ложноположительных срабатываний

В разделе `4. Ложноположительные срабатывания и способы их минимизации` указаны:

- корпоративный VPN;
- антивирусное ПО и средства защиты;
- Docker;
- WSL2;
- Hyper-V;
- VirtualBox;
- QEMU/KVM;
- Android Emulator;
- другие среды виртуализации и контейнеризации;
- NAT, из-за которого GeoIP может определять иной регион.

## Меры снижения ложноположительных срабатываний

В разделе `4` указаны:

- формирование белых списков;
- анализ динамики подключений;
- верификация по портам и протоколам;
- повторная проверка с задержкой;
- комбинирование с другими источниками данных.

## Дополнительные ограничения, влияющие на точность

Из раздела `5.6. Ограничения GeoIP` прямо следуют:

- ограниченная точность для мобильных сетей;
- ограниченная точность для CGNAT;
- ограничения для корпоративных сетей;
- ограничения для пограничных регионов;
- искажения от CDN и глобальных сервисов;
- влияние роуминга;
- отставание репутационных баз;
- сценарии, где пользовательский Proxy выглядит как обычный домашний IP.

Из раздела `7.7. DNS` прямо следуют:

- DNS может быть изменен без VPN;
- пользователь может вручную задать DNS;
- некоторые VPN не меняют DNS;
- локальные DNS-адреса полезны только в комбинации с другими признаками.

Из раздела `7.5. iOS` прямо следует:

- `iCloud Private Relay` не должен автоматически классифицироваться как запрещенный VPN.
